# Sky assets

Generated with ImageGen on November 5, 2026, using the atmosphere in the owner's `Rec 0045.mp4` as the visual reference. The assets contain no site UI, text, sun or moon.

- `day-sky.webp`: 1586×992, 16,232 bytes; pale blue sky with soft thin clouds.
- `night-sky.webp`: 1586×992, 12,632 bytes; deep navy sky with faint clouds and sparse stars.
- `birds.png`: 768×512 RGBA, 11,281 bytes; nine distant bird silhouettes with transparent surroundings.

`sun.svg` (circle-fill) and `moon.svg` (moon-fill) are unmodified Phosphor Icons Core 2.1.1 assets, downloaded from `https://cdn.jsdelivr.net/npm/@phosphor-icons/core@2.1.1/assets/fill/`. Their MIT license is included in `PHOSPHOR-LICENSE`. The sky positions and image glow are controlled in `sky.css`.
